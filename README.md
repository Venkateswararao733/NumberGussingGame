# 🎯 Number Guessing Game (Web Version)
  A simple and interactive **Number Guessing Game** built using **Python (Flask)** and **HTML/CSS**.
  Users can guess a number between **1 and 100** using a web interface, and the app provides feedback like **Too High**, **Too Low**, or **Correct**.
---
## 🚀 Features
  * 🎮 Interactive web-based game
  * 🔢 Random number generation (1–100)
  * 📊 Attempt counter
  * 💬 Instant feedback (Too High / Too Low / Correct)
  * 🌐 Deployable on platforms like Render
---
## 🛠️ Tech Stack
  * **Backend:** Python, Flask
  * **Frontend:** HTML, CSS
  * **Deployment:** Render

## ▶️ How to Run Locally
  1. Clone the repository:
  ```
  git clone https://github.com/Venkateswararao733/NumberGussingGame.git
  cd your-repo-name
  ```
  2. Install dependencies:
  
  ```
  pip install -r requirements.txt
  ```
  3. Run the app:
  ```
  python NumberGuss.py
  ```
  4. Open browser:
  
  ```
http://localhost:10000
```
